# 爱心便签 · 祝福动画（网页版）

由 Python / tkinter 桌面脚本转换而来的**纯前端单文件网页**，无需安装任何环境，点开链接即可观看完整动画。

## 在线预览

- GitHub Pages：https://canyexiren.github.io/heart-blessing/

## 动画流程（循环播放）

| 阶段 | 效果 | 对应原脚本 |
| --- | --- | --- |
| 一 | 75 张马卡龙色便签沿**心形参数方程**逐张浮现 | `step_draw_heart` |
| 二 | 便签自末张起**逐张消散** | `step_shrink_heart` |
| 三 | 180 张便签**随机炸满全屏**，停顿后整体淡出并自动重播 | `step_explode` |

- 心形轨迹使用与原版完全一致参数方程：`x = 16sin³t`，`y = 13cos t − 5cos2t − 2cos3t − cos4t`
- 便签尺寸比例、马卡龙配色表、文案列表、动画节奏（`speed = 0.06`）均与原脚本保持一致
- 支持手机 / 平板 / 桌面自适应；**轻点屏幕可随时重新播放**

## 本地查看

直接双击 `index.html` 即可（单文件、零依赖、无需联网）。

## 文件说明

| 文件 | 说明 |
| --- | --- |
| `index.html` | 网页版（HTML + CSS + 原生 JS，单文件） |
| `heart_blessing.py` | 原始 Python / tkinter 脚本 |

## 与 Python 原版的差异

1. **运行环境**：原版依赖本机 Python + tkinter 弹出多个置顶窗口；网页版用 DOM 元素 + CSS 过渡实现，可跨平台、可通过链接分享。
2. **循环播放**：原版炸屏后画面静止；网页版在炸屏停留约 4 秒后整体淡出并自动重播，避免分享后只看到静止画面。
3. **缩放策略**：原版按 `min(屏幕宽, 屏幕高) / 54` 计算比例；网页版按便签宽度反推同一比例（`便签宽 / 8`），保证小屏手机上心形也完整可见。
